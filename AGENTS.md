# Prompt Log Instructions

After completing each user request in this workspace, append an entry to [prompts.md](./prompts.md) containing:

- **What I asked:** A concise description of the user's request.
- **What you changed:** The files or behavior changed, or state that nothing was changed.
- **Whether it worked:** State the outcome accurately, including if the request was stopped, incomplete, or blocked.

Keep prior entries intact and add new entries at the end. Do not make unrelated project changes just to maintain the log. Respect requests to stop or not proceed; record the outcome without continuing the stopped work. If the user asks not to log a request, do not add an entry for it.

The existing entries cover requests from the conversation in which this file was created. Add future entries only after the corresponding request has been handled.
